# Agent Support

`ctxscope` discovers agent context files by deterministic file patterns.

| Agent | Status | Files |
|---|---|---|
| Codex | Native | `AGENTS.md`, `**/AGENTS.md` |
| OpenCode | Native | `AGENTS.md`, `**/AGENTS.md`, `.opencode/**/*.md`, `.opencode/skills/**/SKILL.md` |
| Claude Code | Native | `CLAUDE.md`, `**/CLAUDE.md`, `AGENTS.md` |
| Cursor | Pattern-based | `.cursor/rules/**` |
| GitHub Copilot | Pattern-based | `.github/copilot-instructions.md` |
| Gemini CLI | Pattern-based | `GEMINI.md` generated by `ctxscope generate` |
| Windsurf | Pattern-based | `.windsurf/rules/ctxscope-generated.md` generated by `ctxscope generate` |
| Generic | Pattern-based | Common markdown context files and rule directories |

Ignored directories include `.git`, `node_modules`, and `dist`.

Limitations:

- Discovery is pattern-based, not runtime session tracing.
- Cursor, Copilot, Gemini, and Windsurf support is conservative.
- `CTX103` path detection recognizes common source and docs path patterns.
- `CTX104` command detection uses repository facts plus a built-in allowlist.

Use `--agent` to narrow scans:

```bash
ctxscope diagnose --agent claude
ctxscope scan --agent opencode
```
